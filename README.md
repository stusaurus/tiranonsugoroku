# ティラノンのあそびば

スマートフォンで遊べる、依存パッケージ不要のミニゲームです。説明を読まなくてもすぐ遊べる、短く気持ちのよいプレイを目指しています。

- **もうひとくちだノン！** — 食べ続けるか、安全に進みを確定するかを選ぶ全23マスのチキンレース
- **ティラノンをうごかそう！** — 3つの命令を並べ、最短クリアを目指す全6ステージ

## ゲームの記録

ブラウザの `localStorage` に、すごろくの最少ターン・最高連続パクパク数と、各プログラミングステージの最高評価を保存します。サーバー通信はありません。

## 起動方法

`index.html` をブラウザで開くか、このディレクトリで静的ファイルサーバーを起動してください。

```sh
python3 -m http.server 8000
```

ビルドは不要です。GitHub Pagesではリポジトリルートを公開元に設定できます。
