# ティラノンのあそびば

スマートフォンで遊べる、依存パッケージ不要のミニゲームです。

- **えらんで進む！すごろく v0.2** — 3枚の移動カードを使い分け、2つの分岐と特殊マスを攻略する戦略すごろく
- **ティラノンをうごかそう！** — 3つの命令を並べ、最短クリアを目指す全6ステージ

## 戦略すごろく

初期手札は `+1 / +2 / +3`。使った1枚だけを山札から補充し、12ターン以内のゴールと高得点を目指します。特殊マスは止まった場合だけ発動します。ゲーム終了後は同じカード順または新しいカード順で再挑戦できます。

## ゲームの記録

ブラウザの `localStorage` に、戦略すごろくの最高得点（`tiranon-strategy-best-score`）と、各プログラミングステージの最高評価（`tiranon-stage-stars`）を保存します。旧すごろくの記録は削除しません。サーバー通信はありません。

## 起動方法

`index.html` をブラウザで開くか、このディレクトリで `python3 -m http.server 8000` を実行してください。ビルドは不要です。
